Live API Access
===============

> ### Requirement
>
>
>
> In order to use Enom's API, you must have your IP address authenticated for use. If you are sending API commands from an IP that is not allowed, you will receive an **"User not permitted from this IP address"** error.

Add or Change an IP for Live Environment
----------------------------------------

You can add your server's IP address to our whitelist from within your account. Here’s how:

To manage the API live environment IP:
1. Login to your Enom account
2. Select the **Resellers** drop down menu
3. Choose **Manage**
4. Select API

Please keep in mind that this IP address should be static, and should be the outbound IP address of the machine that is sending the API calls to our servers.

> ### Important
>
>
>
> Some third-party software applications use Enom's test environment by default. If you receive the error, "Invalid Client IP", please contact the third-party software vendor to find out whether you are operating in the test environment or the live environment and add your IP address as appropriate.
